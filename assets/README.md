# Assets

Drop the following files here before publishing:

- `icon.png` — 1024×1024 app icon (rounded automatically on iOS)
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `splash.png` — 1242×2436 splash image (or any centered logo on `#F4F1EC`)
- `favicon.png` — 48×48 web favicon

You can generate all four from a single 1024×1024 logo via `npx expo-cli generate-icon` or any icon-generator tool. Keep the background `#F4F1EC` to match the app palette.
